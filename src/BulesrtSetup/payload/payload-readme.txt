Bulesrt Launcher —— 空项目版
============================

这个文件夹里只有三样东西：

  BulesrtLauncher.exe   启动器（双击运行）
  data\                 你的全部数据（项目库 data.json、图标缓存、背景图、启动日志）
  说明.txt              本文件

这一版是「空项目版」：装完以后项目库里一条项目都没有；侧栏的「全部」和 7 个
默认分类（游戏 / steam / 我的世界 / 工具 / 软件 / 编程 / 未分类）已经准备好，
自己往里加就行。它也不会像首次启动那样自动去抓桌面快捷方式。

装完默认就是「蓝色插画背景 + 透明图标盒子（深色主题）」：
背景图已经放在 data\background\artwork.png，不想用的话
设置 → 背景 → 「恢复内置深蓝背景」即可。

怎么加项目
----------
1. 右上角 + 号：选一个 exe / 快捷方式 / 网址 / 文件夹，填名字、分类，保存；
2. 或者直接把桌面上的快捷方式拖进窗口；
3. 也可以「批量添加」，一次粘贴多个路径；
4. 想一把抓取桌面和开始菜单：设置 → 数据 → 「重扫快捷方式」。

背景与主题
----------
设置 → 背景：

  选择图片…        挑一张图片或 GIF 动图当背景（复制到 data\background\）
  插画背景          只把内置插画设为背景
  插画 + 透明盒子   一键预设：插画 + 压暗 30% + 图标盒子 100% 透明 + 深色主题
  模糊 / 压暗 / 图标盒子透明 / 主页背景透明   四个滑块，即时预览

运行状态
--------
每 3 秒扫一次进程表，正在运行的项目右上角亮绿点。右键项目可以
「切到运行中的窗口」「结束运行中的实例」「再开一个实例（多开）」。
不想要：设置 → 常规 → 取消勾选「显示运行状态」。

备份 / 迁移
----------
整个文件夹复制走即可。只想备份项目库的话，复制 data\data.json 就够。
升级时覆盖 BulesrtLauncher.exe 即可，data\ 不会被覆盖。

卸载
----
第一种（最方便）：启动器里 设置 → 左下角「卸载…」按钮（就在「取消」旁边），
确认后会关闭启动器，再按安装类型走对应流程：
  装过安装包的 → 拉起安装目录里的 uninstall.exe；
  绿色便携版（目录里没有 uninstall.exe）→ 走启动器内置卸载，
  面板里可以勾选要不要连 data\ 一起删掉。

第二种：Windows 设置 → 应用 → 安装的应用 → 找到「Bulesrt Launcher」→ 卸载。
它会跑安装目录里的 uninstall.exe，删掉程序文件、开始菜单和桌面快捷方式、开机自启，
以及「应用和功能」里的这条记录。

第三种：双击安装目录里的 uninstall.exe（就是当初那个安装包的副本）。
第二、三种的卸载界面里可以勾选「同时删除 data\ 和 plugins\」：
  不勾 → 卸载后只剩 data\ 和 plugins\，以后重装能直接接着用；
  勾选 → 项目库、背景图、图标缓存、装过的插件一起删干净。

第四种（不用卸载程序）：直接删整个文件夹，再去 设置 里关掉「开机自启」，
或删掉注册表 HKEY_CURRENT_USER\Software\Microsoft\Windows\CurrentVersion\Run 下的 BulesrtLauncher 值。

运行要求
--------
Windows 10/11 x64 + .NET 8 桌面运行时。
